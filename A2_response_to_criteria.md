### Core - Statelessness

- **What data is stored within your application that is not stored in cloud data services?:** Temporary transcoding files generated by ffmpeg.
- **Why is this data not considered persistent state?:** They can be recreated from the original S3 file at any time.
- **How does your application ensure data consistency if the app suddenly stops?:** All persistent state (videos, screenshots, tasks) is stored in DynamoDB and S3. Tasks are resumed or retried from DynamoDB records.
- **Relevant files:**

    - /utils/ffmpeg.js
